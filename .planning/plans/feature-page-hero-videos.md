# Feature Page Hero Videos

Potential hero videos/animations for individual feature pages. Each demo corresponds to an existing animated component on the landing demos page.

## 1. SessionDemo — Live Session Experience

**Feature page:** Session / Recording
**Shows:** The actual session recording experience

- Sidebar with mode toggle (Elevator / VC Pitch)
- Recording canvas
- Live transcript with typewriter effect
- Coverage checklist — items progressively check off
- Live metrics: duration, WPM, fillers

## 2. ResultsDemo — Results & Scoring

**Feature page:** Results / Analysis
**Shows:** The actual results page

- Animated score ring (0 → 72)
- Rubric mini-rings for all 5 categories with rationales
- Verdict
- Metrics strip
- Top fixes with impact colors and ranked cards
- Rewrite comparison (original vs. rewrite side-by-side)

## 3. DashboardDemo — Dashboard & Progress

**Feature page:** Dashboard / Progress Tracking
**Shows:** The actual dashboard

- Coach summary card
- Score ring with trend delta
- Sparkline chart
- Radar chart
- Category breakdown bars with animated fill
- Recent sessions list
